This directory holds visual demonstration assets for the **Automated Dataset Quality & Profiling Engine**.

---

## Visual Demonstration Assets

1. **`01_html_quality_report.png`**:

## Capturing Interactive Screenshots in Browser

To capture clean presentation-ready portfolio screenshots in your browser:

1. **Launch the Dashboard:**
   ```cmd
   run.bat
   ```
   Open `http://localhost:8501` in your browser.

2. **Capture Key Screens (Windows Shortcut: `Win + Shift + S`):**

   - **`01_ingestion_view.png`**:
     - Navigate to **"📥 1. Upload & Ingestion"**.
     - Select `Sample: Dirty E-Commerce (Flawed)`.
     - Capture the detected delimiter (`,`), detected encoding (`UTF-8`), row/column counts, and data preview table.

   - **`02_overview_dashboard.png`**:
     - Navigate to **"📊 2. Dataset Overview"**.
     - Capture the Quality Score Hero Card (`70.1 / 100`), 5 Pillars of Data Quality Radar Chart, Missing Values by Column bar chart, and Automated Recommendations expanders.

   - **`03_column_deepdive.png`**:
     - Navigate to **"🔍 3. Column Deep-Dive"**.
     - Select column `unit_price` or `category`.
     - Capture the distribution histogram, Tukey outlier boxplot, IQR bounds, and parametric/non-parametric statistics table.

   - **`04_quality_report_export.png`**:
     - Navigate to **"📑 4. Quality Report & Export"**.
     - Capture the Comprehensive Column Quality Matrix and the 5 download action buttons (HTML, JSON, Markdown, Column Profile CSV, Auto-Cleaned CSV).
